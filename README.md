# Tech Duel — ดวลความรู้เทคโนโลยี 1v1

**เล่นเลย → https://pai1912554.github.io/tech-duel/**

เกมตอบคำถามเทคโนโลยีพื้นฐาน ดวลกับคนจริง 10 ข้อ ข้อละ 30 วินาที
มีระบบชนะต่อเนื่อง และแรงค์ Bronze → Master · ไม่มี dependency ที่ต้องติดตั้ง

## กติกา

- ดวล **10 ข้อ** ข้อละ **30 วินาที** ทั้งสองฝั่งเห็นโจทย์เดียวกันพร้อมกัน
- **ตัวเลือกสลับตำแหน่งทุกข้อ** เจ้าของห้องสุ่มลำดับแล้วส่งไปกับโจทย์ ทั้งคู่จึงเห็นเรียงเหมือนกัน
  แต่คำตอบที่ถูกไม่ได้อยู่ตัวเลือกเดิมตลอด
- คะแนนต่อข้อ = `300 + 700 × สัดส่วนเวลาที่เหลือ` และ **+100 ถ้าตอบเร็วกว่าคู่แข่ง** ตอบผิดได้ 0 ไม่ติดลบ
- เสมอเมื่อครบ 10 ข้อ → ต่อ **Sudden Death** สูงสุด 5 ข้อ ยังเสมออีกตัดสินด้วยจำนวนข้อถูก แล้วจึงเวลารวม
- ออกกลางแมตช์ = แพ้ (ทั้งกดปุ่มออกและปิดแท็บ)
- **ไม่มีบอท** คู่แข่งเป็นคนจริงเท่านั้น

## เล่นกับเพื่อนยังไง

**แบบไม่ต้องตั้งค่าอะไรเลย** — กด "สร้างห้องชวนเพื่อน" จะได้รหัส 4 ตัว ส่งให้เพื่อนกด "เข้าห้องด้วยรหัส"
ต่อตรงระหว่างเบราว์เซอร์ด้วย WebRTC (PeerJS)

> ห้องมีชีวิตอยู่แค่ตอนที่เจ้าของห้องเปิดหน้าเว็บค้างไว้ ปิดแท็บหรือปิดเครื่อง = ห้องหาย
> ทั้งสองคนต้องออนไลน์พร้อมกัน และบอร์ดกับบัญชีแยกตามเครื่อง

**แบบออนไลน์เต็มระบบ** — ตั้งค่า Firebase Realtime Database หนึ่งครั้ง แล้วได้เพิ่ม:
จับคู่อัตโนมัติกับคนที่ MMR ใกล้กัน, ลีดเดอร์บอร์ดรวมของทุกคน, บัญชีที่ล็อกอินได้จากทุกเครื่อง

ตั้งค่าในเกม (ปุ่ม "ตั้งค่าเซิร์ฟเวอร์") หรือแก้ `FIREBASE_URL_DEFAULT` ใน `js/config.js`:

1. เข้า console.firebase.google.com → Add project (ฟรี ไม่ต้องผูกบัตร)
2. Build → Realtime Database → Create Database → เลือก region → Start in **test mode**
3. คัดลอก URL ที่ลงท้าย `firebasedatabase.app` มาวางในเกม
4. คนที่จะเล่นด้วยกันต้องใช้ URL เดียวกัน

> test mode = ใครมี URL ก็อ่านเขียนได้หมด เหมาะกับเกมเล่นกันเองเท่านั้น
> ห้ามใช้ฐานข้อมูลนี้เก็บข้อมูลจริงของใคร และควรตั้งวันหมดอายุของกฎไว้

## ลีดเดอร์บอร์ด

| บอร์ด | เรียงด้วย |
|---|---|
| แรงค์รวม | MMR (รีเซ็ตทุกซีซั่น 30 วัน) |
| 🏅 คะแนนสูงสุด | คะแนนรวมสูงสุดที่เคยทำได้ในแมตช์เดียว |
| ⚡ ตอบเร็วสุด | เวลาตอบเฉลี่ยต่ำสุด ต้องตอบครบ 10 ข้อขึ้นไป |

ทุกบอร์ดปักแถวของตัวเองไว้ล่างสุด พร้อมบอกว่าห่างจากอันดับถัดไปเท่าไหร่

## ระบบอื่นที่มี

**ล็อกอิน** ชื่อ + PIN 6 ตัว ช่องเดียวกันทั้งสมัครและเข้าสู่ระบบ, SHA-256 + salt ต่อผู้ใช้,
ห้ามเลขซ้ำล้วนและเลขเรียง, ผิด 5 ครั้งล็อก 15 นาที, session 30 วัน

**สตรีค** ตัวคูณ ×1.25 / ×1.5 / ×2 ที่ 3 / 5 / 10 · โล่สตรีคที่ 5 ·
กู้สตรีคครึ่งหนึ่งถ้าชนะภายใน 10 นาทีหลังแพ้ · `bestStreak` ไม่มีวันลด

**แรงค์** เก็บ MMR ดิบตัวเดียว คำนวณ tier/div ตอนแสดงผล · Elo + โบนัสสตรีค +
โบนัสล่าหัว 40% เมื่อล้มคนที่ชนะติด 15+ · โล่กันตกแรงค์ทุกครั้งที่เลื่อนขั้น · ซ่อนแรงค์ 5 แมตช์แรก

**โปรไฟล์** W/L, อัตราชนะ, เวลาตอบเฉลี่ย, เรดาร์ความแม่นรายหมวด, ประวัติ 20 แมตช์ กดดูข้อที่ตอบผิดย้อนหลังได้

**คลังคำถาม** กันซ้ำด้วย 50 ข้อล่าสุด · จับคู่ความยากกับ MMR · ปรับ difficulty อัตโนมัติจากอัตราตอบถูก ·
ปุ่มแจ้งข้อผิด 5 ครั้ง = พักคำถามอัตโนมัติ

## ข้อจำกัดที่ต้องรู้

- คำตอบอยู่ใน `js/questions.js` ที่โหลดไปฝั่งผู้เล่น **เปิด DevTools ก็เห็นเฉลย**
  และคะแนนแต่ละข้อคิดจากฝั่งผู้เล่นเอง เป็นเกมที่ตั้งอยู่บนความไว้ใจกัน
- โหมด P2P: บอร์ดและบัญชีอยู่เฉพาะเครื่องนั้น และต้องออนไลน์พร้อมกันทั้งคู่
- โหมด Firebase test mode: ใครมี URL ก็แก้ข้อมูลได้ ถ้าจะใช้จริงจังต้องเพิ่ม Firebase Auth และเขียนกฎ
