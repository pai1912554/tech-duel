# Tech Duel — ดวลความรู้เทคโนโลยี 1v1

**เล่นเลย → https://pai1912554.github.io/tech-duel/**

เกมตอบคำถามเทคโนโลยีพื้นฐาน ดวล 5 ข้อ มีระบบชนะต่อเนื่อง และแรงค์ Bronze → Master
สร้างตาม Build Spec v1 · ไม่มี dependency ภายนอก · ทำงานได้ออฟไลน์ทั้งหมด

## เปิดเล่นในเครื่อง

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย หรือเสิร์ฟผ่าน HTTP:

```bash
python -m http.server 8811 -b 127.0.0.1
```

แล้วเปิด http://localhost:8811

## ระบบที่ทำครบตามสเปก

**ล็อกอิน** — ชื่อ + PIN 6 ตัว ช่องเดียวกันทั้งสมัครและเข้าสู่ระบบ, SHA-256 + salt ต่อผู้ใช้,
ห้ามเลขซ้ำล้วนและเลขเรียง, ผิด 5 ครั้งล็อกชื่อ 15 นาที (ตัวนับอยู่ที่บัญชี ไม่ใช่เครื่อง),
session 30 วัน

**สตรีค** — `streak` (ชนะติดกัน) กับ `dailyStreak` (เข้าเล่นติดกันกี่วัน) แยกกันคนละตัว
ตัวคูณ ×1.25 / ×1.5 / ×2 ที่ 3 / 5 / 10, โล่สตรีคที่ 5, กู้สตรีคครึ่งหนึ่งถ้าชนะภายใน 10 นาทีหลังแพ้,
`bestStreak` ไม่มีวันลด, `applyResult()` คืน list ของ event ให้หน้าจอเล่นทีละอันตามคิว

**การดวล** — 5 ข้อ ข้อละ 10 วิ, สูตร `300 + 700×เวลาที่เหลือ` (+100 ถ้าเร็วกว่าคู่แข่ง),
โชว์ "คู่แข่งตอบแล้ว" โดยไม่บอกว่าถูกหรือผิด, เฉลย 2 วิทุกข้อ, เสมอ = Sudden Death,
ปิดแท็บหรือสลับแท็บกลางแมตช์ = แพ้ทันที

**แรงค์** — เก็บ `mmr` ดิบตัวเดียว คำนวณ tier/div ทุกครั้งที่แสดงผล,
Elo + โบนัสสตรีค + โบนัสล่าหัว 40% เมื่อล้มคนที่ชนะติด 15+,
โล่กันตกแรงค์แจกทุกครั้งที่เลื่อน tier, ซ่อนแรงค์ 5 แมตช์แรก

**บอร์ด** — แรงค์รวม / สตรีคร้อนแรง / สถิติสตรีค / เพื่อน ปักแถวตัวเองไว้ล่างสุดพร้อมบอกส่วนต่าง

**โปรไฟล์** — ป้ายแรงค์, W/L, อัตราชนะ, เวลาตอบเฉลี่ย, เรดาร์ความแม่นรายหมวด,
ประวัติ 20 แมตช์ กดดูข้อที่ตอบผิดย้อนหลังได้

**คลังคำถาม** — กันซ้ำด้วย `recentIds` 50 ตัวล่าสุด, จับคู่ความยากกับ MMR,
ปรับ difficulty อัตโนมัติจากอัตราตอบถูก, ปุ่มแจ้งข้อผิด (5 ครั้ง = พักคำถามอัตโนมัติ),
เก็บ `times[]` ของทุกคนไว้ป้อนระบบผี

## คู่แข่ง

ตอนเริ่มเกมจะ seed บอท 24 ตัวลงฐานข้อมูล เพื่อให้ลีดเดอร์บอร์ดไม่ว่างตั้งแต่วันแรก
บอทมี MMR / สตรีค / สถิติของตัวเอง และ **ผลแมตช์อัปเดตฝั่งบอทด้วย** บอร์ดจึงขยับจริงตามการเล่น
เวลาตอบของบอทหยิบจากเวลาตอบจริงของคนที่ MMR ใกล้กัน (`ghostAnswer`) ถ้ายังไม่มีข้อมูลค่อยจำลองตามระดับความยาก

## ข้อจำกัดที่ต้องรู้

- ข้อมูลทั้งหมดอยู่ใน `localStorage` ของเครื่องนี้ **ใครเปิด DevTools ก็แก้แต้มตัวเองได้** ต้องมีเซิร์ฟเวอร์ถึงจะกันได้จริง
- PIN 6 หลักมีความเป็นไปได้แค่ 1 ล้านแบบ ระบบล็อกช่วยได้ระดับหนึ่ง แต่**อย่าใช้รหัสเดียวกับบัญชีอื่น**
- คำตอบถูกส่งไปพร้อมคำถามในฝั่งเบราว์เซอร์ (ไม่มีเซิร์ฟเวอร์ให้ซ่อน) — ขั้นตอนที่ 6 ในสเปกจะแก้เรื่องนี้
